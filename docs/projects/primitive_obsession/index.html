Primitive Obsession

A large-scale volumetric display debuting in 2025.

red.it.be

Project Details

Primitive Obsession is an homage to the beauty of simple geometric shapes. The installation showcases a collection of digital works, including interactive games, crowd reactive effects, and live VJ'd music-reactive visuals.

The installation stands 12' x 12' x 12' in an open frame, with the LEDs hanging freely from above. Revelers are free to enter the installation and walk around inside, pushing the LED strands aside as if in an inverted field of digital grass. Interactivity is facilitated by way of depth cameras and control podiums with arcade buttons.

The installation is ruggedized by way of steel cabling reinforcing the LED curtains and plastic sleeves mounted on all strands. The structure is ratchet strapped to the ground and is designed with a minimal drag cross section to withstand high winds. The installation is also modular; the conduit frame can be scaled arbitrarily in all dimensions, with additional LED modules added as needed to achieve any multiple of 10' x 10' x 10'.

Technical Specifications

Per Module:

  • 20 x 20 x 20 WS2815 LEDs
  • 2x COTS ArtNET 12-channel controllers
  • 2x 50A 12V power supplies
  • Industrial ethernet switch
  • Custom 10' x 10' x 10' EMT conduit frame

Per System:

  • Mac Mini
  • OAK-D depth camera
  • TouchDesigner
  • Rust/Python orchestration layer
  • 4x custom PoE-enabled control podiums

Software & Firmware:

  • Main Display Software - Core volumetric display control system
  • Control Podium Firmware - Custom ethernet controller for interactive podiums
